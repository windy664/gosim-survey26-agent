# 03 · 任务卡与赛程

## 1. 练习卡（现已全部公开，含天气真值，可本地复现得分）

| 卡 | 巡天季（38 夜） | 目标 / 必观测 | 天区 | 特殊机制 |
|---|---|---|---|---|
| α | 2026-10-04 起 | 10,000 / 500（5%） | 2000 deg² | 只有天气 |
| β | 2026-10-18 起 | 9,600 / 480 | 1920 deg² | 天空随季节移动，目标分布在其他位置 |
| γ | 2026-10-09 起 | 9,900 / 495 | 1980 deg² | **+ data_loss（一次）** |
| δ | 2026-10-24 起 | 9,400 / 564（6%） | 1880 deg² | **+ data_loss**，必观测比例更高，超难卡 |

- 台址均为虚拟智利 Paranal（−24.6157°, −70.3976°，utc_offset −4）。
- **光纤数以 `initialize` 下发为准**：规则页称四张练习卡分别为 **16、25、9、100** 根（α/β/γ/δ 顺序）；卡页"一览"的 4×4 是模板文本，勿信。
- 练习赛在云端对 α–δ 各跑一次，同样 900 秒/卡；成绩只进练习榜，**不决定奖项**。
- `data_loss`/`pointing_offset` 属 Hard mode，只在启用卡出现（γ、δ 已确认有 data_loss）。

## 2. 正式卡 A–D（北京时间 10 月 5 日 00:00 公开）

- 四张卡固定、对所有队伍相同（不按队随机）。
- 公开内容：卡片说明页 + 公开输入（目标、天区、站点、光纤、观测日程、计分参数）；**天气、预报、事件、故障不公开**，运行时逐步下发。
- 每次评测在 A–D 上各跑一次；**线上榜成绩 = 四卡算术平均**，四卡全部完成才上榜；取每队最高分的一次评测，不能拼接不同次评测的单卡最高分。
- 第 4 张 D 为超难卡。
- 每次评测结果 ZIP 可下载复盘。

## 3. 隐藏卡 E–H（决赛）

- 选手永远看不到；线上赛截止后由主办方对每队**最终版本**各评测一次（900 秒/卡，不占每日额度），最终排名 = E–H 算术平均，**线上榜不决定名次**。
- 讲座口径：**3 张简单 + 1 张超难**，与赛题同构、仅数据（目标/季节/月相/事件时刻）不同；赛后公布全部日志与卡片文档供自查。
- 结论：**策略必须泛化**，任何写死 A–D 具体天况的逻辑都是负资产。
- 注意：隐藏决赛评测**无法使用"不保存"模式的模型密钥**——会调大模型的程序必须在截止前切换为"加密保存"。

## 5. 参赛规则要点

- 队伍 1–3 人，每人一队；提交以队伍名义。队伍总数有上限，满额后报名关闭（可凭邀请码加入已有队伍）。
- 每日评测额度以「参赛」页实时显示为准（讲座称已扩容）；平台原因失败不计次，**自身构建失败/崩溃/协议错误照常计次**。
- 模型 API：自备，OpenAI 兼容 https 公网地址（禁 IP/内网）。密钥两模式：**加密保存**（默认，决赛必需，核验后自动删除）/ **不保存**（评测期间页面必须保持打开）。不要把密钥写进源码。
- Kimi Coding Plan：跑通练习赛的前 100 队每队一码（先到先得），队长在控制台领取；接口 `https://api.kimi.com/coding/v1`，模型 `kimi-for-coding` 或 `k3`。
- 评奖硬门槛：自然语言理解、数据解析、任务规划、行动决策、工具调用、自适应六环节中**至少两个由 LLM 驱动**（官方用 Claude 做代码分析判定）；纯代码可参赛但不评奖。官方口径倾向"真正调用"，部署不调不算。
- 禁止：人工参与决策、共享账号、多队刷额度、读取他队数据、篡改评分。
