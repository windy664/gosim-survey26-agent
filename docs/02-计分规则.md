# 02 · 计分规则

来源：官方指南 §5–7（公式 17–22）。示例参数（q0=0.68、f0=0.5、T0=900s、β=0.6 等）以 `initialize.payload.scoring` 实际下发为准，**不要硬编码**。

## 1. 单次曝光的目标质量 Q（公式 17）

曝光先在天气 slot 边界和事件起止切分，再细分为 ≤120 秒片段：

```
Q(i,e) = 1/(q0·T_e) · Σ_p Δt_p · C(i,p) · [ η(i,p)·τ(i,p)·K(i,p)·L_i(t_p) / ( s(i,p)·X(h_i(t_p))^β ) ]
```

- `C`：片段中点可观测指示（夜间天气数据存在、站点开放、无覆盖该目标的关闭事件 → 1，否则 0）。**关闭片段仍占分母**——坏天气曝光是净亏。
- `η` 仪器效率（受故障影响）、`τ` 透过率、`K` sky_quality、`s` seeing（均隐藏，只能靠得分反推）
- `L_i` 月光因子（公式 14，公开可算：P_M=0.75、γ_M=1、θ_M=35°）：月越亮、越高、离目标越近，惩罚越重；月在地平线下 = 1
- `X(h)` 归一化大气质量（公式 15，公开可算）；`β=airmass_exponent`（示例 0.6）

## 2. 完成因子与基础分（公式 18）

```
g(i,e) = min( f_i · T_e · Q(i,e) / (f0·T0), 1 )     完成因子，上限 1
s(i,e) = w_i · g(i,e)                               基础科学贡献，上限 w_i
```

- `f_i` = `feature_flux`（相对亮度），`w_i` = `science_weight`
- 暗目标需要更长曝光；达上限后加时无收益 → 按 `T = f0·T0/(f_i·Q̂)` 反推最优曝光时长

## 3. 观测程序加成（公式 19、20）

对每个命中目标独立计算程序质量 B（**不含**仪器效率 η、方向性事件乘数、目标方向关闭项；但含站点天气、月光、大气质量）：

```
B ≥ bands.DARK(0.65)  → 实际 DARK 档
B ≥ bands.BRIGHT(0.40) → 实际 BRIGHT 档
其余                  → 实际 BACKUP 档
```

声明与实际档位匹配：`DARK ×1.20`、`BRIGHT ×1.12`、`BACKUP ×1.06`；不匹配 ×`mismatch_multiplier`(1.00)。**一次曝光只声明一个 program，视场内不同目标档位可不同**，只有匹配的目标吃加成。最终该次得分 `c(i,e) = s(i,e) · m(i,e)`。

含义：B 不用仪器效率 → 仪器故障不影响 program 判档；但坏天气会把全场档位压向 BACKUP。

## 4. 最终结算（公式 22）

```
S = Σ_i best_i  −  P_req·N_missing  −  U·(1−J)  +  R_request  +  S_report
```

- `best_i = max_e c(i,e)`：**同一目标多次曝光只取最高一次**，不累加。最高分与完成状态可来自不同曝光。
- `required` 门槛：`g_req = 0.5`（用**不含 program 加成**的原始 g）；每漏一个罚 `P_req`（示例 50）。
- 均匀度：按 `ra_band_width_deg`（示例 10°）分赤经带，只计含目标的带；带内比例 r_b = 达 0.5 门槛的目标数/带内总数（同一门槛，不乘权重）；Jain 指数 `J = (Σr)²/(N·Σr²)`，罚 `U·(1−J)`（示例 U=200，全零时 J=0）。
- 限时请求：窗内完整有效的曝光自动归入所有适用请求；达 `minimum_completed` 个（各过 `completion_factor_threshold` 0.5）得 `completion_reward`（示例 100）；未完成不扣分。
- 举报：正确 +100 并立即修复；每次正确举报后前 `false_report_free_allowance`（示例 2）次误报免罚，之后每次 −150；`wait`/`observe` 不清误罚计数，只有正确举报清零。

## 5. 数值示例（卡页原文）

目标亮度 0.60、权重 1.0，曝光 900s，天空质量 0.75：
`g = 0.60×900×0.75/450 = 0.90`；声明 DARK 且实际 DARK → `1.0×0.90×1.20 = 1.08`。
若只曝光 300s：g=0.30 < 0.5 门槛 → required 目标仍算漏掉。

## 6. 策略推论

1. **时间预算是核心资源**：ΣT_e 有限（每夜仅 36 个 900s slot 量级），曝光时长应按 `f0·T0/(f_i·Q̂)` 贴着 g=1 定，暗目标果断长曝或放弃。
2. **required 优先**：漏一个 −50，g 门槛 0.5 且不吃 program 加成 → 对每个 required 目标排一次"能过 0.5"的保底曝光。
3. **均匀度**：200 分权重不小，前期铺覆盖、后期补低 r_b 条带；周/月维度复盘 G 指数。
4. **program 声明**：曝光内选占主导的档位；天气差时 BACKUP 反而匹配更多目标。
5. **刷分机制**：好天气时可对高权重目标重曝提 best；窗口紧的目标优先。
6. **report 纪律**：需要持续性低分证据（排除天气解释）再举报；误报 −150 代价高。
7. **900s 墙钟**：每轮都调 LLM 必超时 → LLM 只用于低频决策（每晚建议等），slot 级决策用确定性算法。
